Raspberry Pi Pico · RP2040 · MAX7219 · FFT

Pico Pitch / Chord /
Bass Line Analyzer

Компактный анализатор аудиосигнала для определения высоты ноты, анализа басовой линии, распознавания трезвучий и аккордов, частотного анализа и настройки музыкальных инструментов.

GitHub Режимы работы Аппаратная часть

Что это?

Это не гармонизатор в классическом смысле. Прибор анализирует уже существующий аудиосигнал и пытается определить содержащуюся в нём музыкальную информацию. Основная идея проекта — объединить Pitch, Chord и Bass Line анализатор в компактном устройстве на Raspberry Pi Pico.

Аудиосигнал→ ADC→ FFT→ Анализ частот→ Ноты / Аккорды→ MAX7219

Режимы

Pitch

Высота звука

Определение основной частоты и соответствующей музыкальной ноты.

Piano

Фортепианный диапазон

Сопоставление обнаруженной частоты с нотами фортепианной клавиатуры.

Bass

Басовый анализ

Анализ низкочастотного диапазона и басовых нот/линии.

Triad

Трезвучия

Поиск комбинаций из трёх нот и их сопоставление с типами трезвучий.

Chord

Аккорды

Анализ нескольких одновременно звучащих нот и распознавание аккордов.

Osc

Визуальный анализ

Режим визуального отображения характеристик входного сигнала/спектра.

Tuner

Тюнер

Использование определённой частоты для настройки музыкального инструмента.

Аппаратная часть

Raspberry Pi Pico

RP2040, два ядра ARM Cortex-M0+, проект рассчитан на частоту 200 MHz.

MAX7219

Светодиодная матрица используется для отображения режимов, нот и результатов анализа.

ADC + FFT

Встроенный ADC получает аудиосигнал, а arduinoFFT используется для спектрального анализа.

Аудиовход

Перед подключением аудио к ADC необходимо проверить уровень сигнала. Нельзя подавать неизвестный источник непосредственно на ADC, если его напряжение может выйти за допустимый диапазон RP2040. Для переменного аудиосигнала обычно требуется соответствующее смещение относительно середины диапазона ADC.

Как работает анализ

Сигнал поступает на ADC, накапливается в буфере и обрабатывается цифровыми алгоритмами. FFT переводит сигнал из временной области в частотную. По спектру программа определяет основные частоты и сопоставляет их с музыкальными нотами. Набор найденных нот используется для анализа трезвучий и аккордов.

Установка

  1. Установить Arduino IDE.
  2. Установить поддержку Raspberry Pi Pico / RP2040.
  3. Установить библиотеки MD_MAX72XX и arduinoFFT.
  4. Открыть файл проекта .ino.
  5. Выбрать плату Raspberry Pi Pico.
  6. Проверить GPIO аудиовхода, кнопки и MAX7219.
  7. Скомпилировать и загрузить прошивку.

Управление

Pitch → Piano → Bass → Triad → Chord → Osc → Tuner → Pitch

При переключении режима его название кратковременно отображается на матрице.

Используемые библиотеки

MD_MAX72XX

Управление LED-матрицей MAX7219 через SPI.

SPI

Последовательный интерфейс, используемый для связи с MAX7219.

arduinoFFT

Быстрое преобразование Фурье для частотного анализа аудиосигнала.

Предупреждения компиляции

Сообщение INFO: ARDUINO SPI interface selected. от MD_MAX72XX является информационным предупреждением о выбранном SPI-интерфейсе и не является ошибкой.

Предупреждение ISO C++ forbids converting a string constant to 'char*' возникает, когда строковый литерал передаётся функции с параметром char*. Корректная сигнатура для таких строк: 

void flash_message(const char *message);

Ограничения

Точность определения нот и аккордов зависит от качества сигнала, шума, обертонов, уровня входного сигнала, частоты дискретизации, размера FFT, тембра инструмента и количества одновременно звучащих источников.
