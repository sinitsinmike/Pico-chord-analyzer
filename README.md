# Pico Pitch / Chord / Bass Line Analyzer

Компактный анализатор аудиосигнала на базе **Raspberry Pi Pico (RP2040)**.

Проект предназначен для анализа музыкального сигнала в реальном времени: определения высоты ноты (**Pitch**), анализа басового диапазона и басовой линии (**Bass**), распознавания трезвучий (**Triad**) и аккордов (**Chord**), а также визуального анализа сигнала и использования прибора как тюнера.

> **Рабочее название проекта:** Pico Pitch / Chord / Bass Line Analyzer  
> Старое название `Harmonalyzer` сохранено в исходном коде/истории проекта, но оно не полностью отражает назначение прибора.

## Возможности

Прибор имеет несколько режимов:

- **Pitch** — определение основной частоты и соответствующей музыкальной ноты.
- **Piano** — определение нот в диапазоне фортепиано.
- **Bass** — анализ низкочастотного диапазона и басовых нот.
- **Triad** — распознавание трезвучий.
- **Chord** — распознавание одновременно звучащих нот и аккордов.
- **Osc** — визуальный режим анализа входного сигнала/спектра.
- **Tuner** — режим музыкального тюнера.

Переключение режимов выполняется кнопкой управления.

## Аппаратная часть

### Контроллер

- Raspberry Pi Pico
- микроконтроллер RP2040
- два ядра ARM Cortex-M0+
- тактовая частота проекта: 200 MHz

### Дисплей

Используется светодиодная матрица на базе **MAX7219**.

Управление выполняется через библиотеку:

- `MD_MAX72XX`
- интерфейс SPI

### Анализ аудио

Входной аудиосигнал оцифровывается встроенным ADC RP2040.

Для спектрального анализа используется:

- `arduinoFFT`

Общая цепочка обработки:

```text
Аудиосигнал
     │
     ▼
   ADC
     │
     ▼
Буфер отсчётов
     │
     ▼
Предобработка
     │
     ▼
    FFT
     │
     ▼
Анализ спектра
     │
     ├──► Pitch
     ├──► Piano
     ├──► Bass
     ├──► набор нот
     │       │
     │       ├──► Triad
     │       └──► Chord
     │
     └──► Osc / Tuner
```

## Подключение

### MAX7219

В текущей конструкции матрица питается непосредственно от Raspberry Pi Pico:

| MAX7219 | Raspberry Pi Pico |
|---|---|
| VCC | +5V |
| GND | GND |
| DIN | SPI MOSI |
| CLK | SPI SCK |
| CS / LOAD | GPIO, указанный в программе |

**Важно:** конкретные GPIO для `DIN`, `CLK` и `CS` необходимо брать из используемой версии `.ino`, поскольку они являются частью конфигурации программы.

Матрица подключается к:

- `+5V` Pico
- `GND` Pico

Для больших матриц или нескольких модулей MAX7219 следует учитывать потребляемый ток. В таком случае рекомендуется отдельное стабильное питание 5 V с общей землёй с Pico.

### Аудиовход

Аудиосигнал поступает на аналоговый вход RP2040.

Перед подключением необходимо убедиться, что напряжение на ADC находится в допустимом диапазоне входа микроконтроллера.

Нельзя подавать на ADC неизвестный аудиосигнал напрямую без проверки его уровня.

Для обычного переменного аудиосигнала может потребоваться входная схема со смещением относительно середины диапазона ADC.

В качестве источника сигнала можно использовать:

- линейный выход;
- микрофон с предусилителем;
- звукосниматель с подходящим предусилителем;
- музыкальный инструмент;
- другой аналоговый источник аудиосигнала.

## Режимы работы

### Pitch

Определяется основная частота входного сигнала и переводится в музыкальную ноту.

Например:

```text
440 Hz → A4
```

Режим предназначен прежде всего для анализа отдельных нот и монодических источников.

### Piano

Режим ориентирован на диапазон фортепиано. Обнаруженная частота сопоставляется с соответствующей нотой фортепианной клавиатуры.

### Bass

Режим предназначен для анализа низкочастотного диапазона.

Может использоваться для:

- бас-гитары;
- контрабаса;
- синтезатора;
- басовой линии;
- других низкочастотных музыкальных сигналов.

### Triad

Анализируется набор обнаруженных нот, после чего выполняется сопоставление с известными вариантами трезвучий.

Например:

```text
C + E + G
     │
     ▼
  C major
```

### Chord

Расширенный режим анализа нескольких одновременно звучащих нот.

Распознавание зависит от качества входного сигнала, спектра, обертонов и алгоритма сопоставления.

### Osc

Визуальный режим анализа входного сигнала/спектра.

### Tuner

Режим музыкального тюнера, использующий определённую частоту для оценки высоты ноты.

## Управление

Режимы переключаются последовательно:

```text
Pitch
  ↓
Piano
  ↓
Bass
  ↓
Triad
  ↓
Chord
  ↓
Osc
  ↓
Tuner
  ↓
Pitch
```

При переключении режима его название кратковременно отображается на матрице.

## Программное обеспечение

Проект рассчитан на **Arduino IDE** и плату **Raspberry Pi Pico**.

Используемые библиотеки:

- `MD_MAX72XX`
- `SPI`
- `arduinoFFT`

Проверенная конфигурация разработки:

```text
Raspberry Pi Pico
RP2040
MD_MAX72XX 3.5.1
SPI 1.0
arduinoFFT 2.0.4
```

## Установка

1. Установить Arduino IDE.
2. Установить поддержку плат Raspberry Pi Pico / RP2040.
3. Установить библиотеки `MD_MAX72XX` и `arduinoFFT`.
4. Открыть файл `.ino` проекта.
5. Выбрать плату **Raspberry Pi Pico**.
6. Проверить GPIO аудиовхода, кнопки и MAX7219 в исходном коде.
7. Выполнить компиляцию.
8. Загрузить прошивку в Pico.

Если Arduino IDE завершает компиляцию без `error` и показывает успешную сборку, проект собран корректно.

## Два ядра RP2040

Проект использует возможности двухъядерного RP2040.

Инициализация ADC выполняется в `setup1()`:

```cpp
void setup1()
{
  adc_init();
  adc_gpio_init(ADC_PIN);
  adc_select_input(ADC_CHANNEL);
  prev_time = micros();
  mx.control(MD_MAX72XX::INTENSITY, 1);
}
```

Яркость матрицы MAX7219 задаётся значением `0...15`. Для начала рекомендуется небольшая яркость, например `1...3`.

Если `mx` относится к дисплею, инициализацию самого дисплея следует выполнять в основном `setup()` согласно структуре текущей версии программы.

## FFT и обработка сигнала

FFT используется для перехода от временного представления сигнала к частотному.

Это позволяет анализировать:

- основную частоту;
- присутствующие гармоники;
- набор частот;
- низкочастотную составляющую;
- комбинации нот, используемые при определении аккордов.

Точность анализа зависит от частоты дискретизации, размера FFT, качества входного сигнала и уровня шума.

## Ограничения

Распознавание аккордов и нот не является абсолютным. На результат могут влиять:

- шум;
- обертоны;
- реверберация;
- недостаточный уровень сигнала;
- перегрузка ADC;
- несколько одновременно звучащих инструментов;
- слишком короткое окно анализа;
- особенности тембра инструмента;
- неточная настройка инструмента.

Для стабильного распознавания желательно использовать достаточно чистый сигнал.

## Предупреждения компилятора

Сообщение:

```text
warning: #warning "INFO: ARDUINO SPI interface selected."
```

выдаётся библиотекой `MD_MAX72XX`. Это информационное предупреждение о выбранном SPI-интерфейсе, а не ошибка проекта.

Если встречается:

```text
ISO C++ forbids converting a string constant to 'char*'
```

например при:

```cpp
flash_message("Pitch");
```

то функция должна принимать строку как константную:

```cpp
void flash_message(const char *message)
```

Это позволяет корректно передавать строковые литералы.

## Безопасность

Перед включением питания проверьте:

1. Полярность питания MAX7219.
2. Общий `GND`.
3. Отсутствие короткого замыкания между `+5V` и `GND`.
4. Напряжение на ADC.
5. Подключение `DIN`, `CLK` и `CS`.
6. Соответствие GPIO в программе фактической распиновке.
