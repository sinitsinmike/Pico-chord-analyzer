# Harmonalyzer

**Harmonalyzer** — компактный музыкальный анализатор на базе **Raspberry Pi Pico**.

Прибор принимает аудиосигнал, анализирует его с помощью цифровой обработки сигнала и отображает музыкальную информацию на светодиодной матрице **MAX7219**.

Проект предназначен для определения высоты звука, нот и аккордов, а также для визуального отображения музыкальной информации в реальном времени.

---

## Возможности

Прибор поддерживает несколько режимов работы:

- **Pitch** — определение основной частоты и высоты звучащего сигнала.
- **Piano** — отображение нот в соответствии с клавиатурой фортепиано.
- **Bass** — режим анализа басового диапазона.
- **Triad** — определение трезвучий.
- **Chord** — определение аккордов.
- **Osc** — визуализация сигнала/спектра.
- **Tuner** — режим музыкального тюнера.

Переключение режимов осуществляется кнопкой управления.

---

## Аппаратная часть

Основной контроллер:

- Raspberry Pi Pico
- RP2040
- частота CPU: 200 MHz

Дисплей:

- LED-матрица на базе MAX7219
- библиотека `MD_MAX72XX`
- интерфейс SPI

Анализ аудиосигнала:

- встроенный ADC RP2040
- цифровая обработка полученных отсчётов
- FFT-анализ с использованием библиотеки `arduinoFFT`

## Подключение

### Raspberry Pi Pico

Типовое подключение матрицы MAX7219:

| MAX7219 | Raspberry Pi Pico |
|---|---|
| VCC | +5V |
| GND | GND |
| DIN | SPI MOSI |
| CLK | SPI SCK |
| CS / LOAD | GPIO, указанный в программе |

Конкретные GPIO для `DIN`, `CLK` и `CS` должны соответствовать значениям, заданным в исходном файле `harmonalyzer2.ino`.

### Питание матрицы

Матрица в текущей конструкции питается от:

- `+5V` Raspberry Pi Pico
- `GND` Raspberry Pi Pico

Общий GND между Pico и аудиотрактом обязателен.

Если используется большая матрица или несколько модулей MAX7219, необходимо учитывать потребляемый ток. В таком случае рекомендуется отдельный стабильный источник 5 V с объединённой землёй с Pico.

---

## Аудиовход

Аудиосигнал поступает на аналоговый вход Raspberry Pi Pico.

Сигнал перед подачей на ADC должен находиться в допустимом диапазоне входного напряжения RP2040.

**Нельзя подавать непосредственно на ADC сигнал, который может выйти за допустимый диапазон входа.**

Для аудиосигнала обычно требуется схема смещения относительно середины диапазона ADC.

Источник сигнала может быть:

- микрофон;
- линейный выход;
- звукосниматель;
- предусилитель;
- другой аналоговый аудиосигнал.

---

# Принцип работы

Harmonalyzer работает как цифровой анализатор аудиосигнала.

Упрощённая схема обработки:

```text
Аудиосигнал
     │
     ▼
Аналоговый вход
     │
     ▼
    ADC
     │
     ▼
Буфер отсчётов
     │
     ▼
Предобработка
     │
     ▼
    FFT
     │
     ▼
Анализ спектра
     │
     ├──► Основная частота
     │
     ├──► Нота
     │
     ├──► Басовый диапазон
     │
     └──► Набор нот
              │
              ▼
        Определение аккорда
              │
              ▼
       LED-матрица MAX7219
```

---

# Определение высоты звука

В режиме `Pitch` прибор анализирует входной сигнал и пытается определить его основную частоту.

После получения частоты она преобразуется в музыкальную ноту.

Например:

```text
440 Hz → A4
```

---

# Определение аккордов

В режимах `Triad` и `Chord` прибор анализирует набор обнаруженных нот.

Для комбинаций нот выполняется сопоставление с таблицей известных аккордов.

Например:

```text
C + E + G
      │
      ▼
   C major
```

Для аккордов учитываются входящие в них интервалы и ноты.

---

# Режимы

## Pitch

Режим определения основной высоты звука.

Подходит для:

- отдельных нот;
- вокала;
- музыкальных инструментов;
- проверки высоты тона.

## Piano

Режим ориентирован на диапазон фортепиано.

Обнаруженная частота преобразуется в соответствующую ноту фортепианной клавиатуры.

## Bass

Режим предназначен для работы с низкочастотными сигналами.

Может использоваться при анализе:

- бас-гитары;
- контрабаса;
- синтезатора;
- низких частот музыкального сигнала.

## Triad

Режим анализа трезвучий.

Прибор ищет комбинации из трёх нот и сравнивает их с известными типами трезвучий.

## Chord

Расширенный режим определения аккордов.

Используется для анализа нескольких одновременно звучащих нот.

## Osc

Визуальный режим для отображения характеристик входного сигнала.

## Tuner

Режим музыкального тюнера.

Позволяет использовать Harmonalyzer для настройки музыкального инструмента по обнаруженной частоте.

---

# Управление

Кнопка используется для переключения режимов:

```text
Pitch
  ↓
Piano
  ↓
Bass
  ↓
Triad
  ↓
Chord
  ↓
Osc
  ↓
Tuner
  ↓
Pitch
```

При переключении режима на дисплее кратковременно отображается его название.

# Светодиодная матрица

Для управления матрицей используется библиотека:

`MD_MAX72XX`

Яркость MAX7219 задаётся программно.

Например:

```cpp
mx.control(MD_MAX72XX::INTENSITY, 1);
```

Диапазон яркости:

```text
0 ... 15
```

Для начала рекомендуется использовать небольшое значение яркости, например `1–3`.

# Установка

## 1. Установить Arduino IDE

Установите Arduino IDE и поддержку плат Raspberry Pi Pico / RP2040.

## 2. Установить библиотеки

В Arduino IDE установите:

```text
MD_MAX72XX
arduinoFFT
```

Библиотека `SPI` входит в платформу Arduino/RP2040.

## 3. Открыть проект

Откройте:

```text
harmonalyzer2.ino
```

## 4. Выбрать плату

В Arduino IDE выберите:

```text
Raspberry Pi Pico
```

## 5. Проверить GPIO

Перед прошивкой необходимо убедиться, что GPIO в программе соответствуют реальному подключению:

- аудиовход;
- кнопка;
- DIN матрицы;
- CLK матрицы;
- CS матрицы.

## 6. Скомпилировать

Нажмите `Verify` / `Проверить`.

Если компиляция завершилась сообщением:

```text
exit status 0
```

прошивка успешно собрана.

## 7. Загрузить прошивку

Подключите Raspberry Pi Pico к компьютеру через USB, выберите соответствующий порт и нажмите `Upload`.

# Архитектура программы

Программа использует два ядра RP2040.

Основная логика работает на основном ядре, а сбор данных ADC может выполняться на втором ядре.

Инициализация ADC выполняется в:

```cpp
void setup1()
{
  adc_init();
  adc_gpio_init(ADC_PIN);
  adc_select_input(ADC_CHANNEL);
  prev_time = micros();
}
```

Инициализация дисплея выполняется в основном:

```cpp
void setup()
{
  mx.begin();
  mx.control(MD_MAX72XX::INTENSITY, 1);
}
```

# Используемые технологии

## RP2040

Микроконтроллер Raspberry Pi Pico с двумя ядрами ARM Cortex-M0+.

Использование второго ядра позволяет отделить сбор аудиоданных от основной логики приложения.

## ADC

Аналогово-цифровой преобразователь используется для получения цифровых отсчётов аудиосигнала.

Полученные значения помещаются в буфер для дальнейшего анализа.

## FFT

Быстрое преобразование Фурье позволяет представить аудиосигнал в частотной области.

Вместо непосредственного анализа формы сигнала программа получает информацию о присутствующих частотах.

Используемая библиотека:

```text
arduinoFFT
```

## MAX7219

MAX7219 используется для управления светодиодной матрицей.

Он упрощает управление большим количеством светодиодов посредством последовательного интерфейса.

# Предупреждения компилятора

При сборке проекта может появляться предупреждение:

```text
warning: #warning "INFO: ARDUINO SPI interface selected."
```

Это информационное сообщение библиотеки `MD_MAX72XX` о выбранном SPI-интерфейсе. Оно не является ошибкой компиляции.

Также могут встречаться предупреждения вида:

```text
ISO C++ forbids converting a string constant to 'char*'
```

Они возникают, если функция объявлена, например, так:

```cpp
void flash_message(char *message)
```

а вызывается со строковым литералом:

```cpp
flash_message("Pitch");
```

Корректнее использовать:

```cpp
void flash_message(const char *message)
```

# Безопасность подключения

Перед включением питания проверьте:

1. Полярность питания матрицы.
2. Общий GND между узлами.
3. Отсутствие короткого замыкания между `+5V` и `GND`.
4. Напряжение, поступающее на ADC.
5. Правильность подключения SPI.
6. Правильность GPIO, указанных в программе.

Не подключайте неизвестный аудиосигнал непосредственно к ADC без проверки его уровня.

# Диагностика

## Матрица не светится

Проверьте:

- `VCC`;
- `GND`;
- `DIN`;
- `CLK`;
- `CS`;
- выбранный SPI-интерфейс;
- количество подключённых модулей MAX7219.

Также проверьте наличие:

```cpp
mx.begin();
```

в `setup()`.

## Матрица работает, но отображает мусор

Проверьте:

- порядок подключения DIN/CLK/CS;
- тип используемого модуля;
- количество устройств в цепочке;
- настройки `MD_MAX72XX`;
- ориентацию матрицы.

## Нет корректного определения ноты

Проверьте:

- уровень входного сигнала;
- наличие общего GND;
- смещение аудиосигнала относительно ADC;
- частоту дискретизации;
- размер FFT;
- качество входного сигнала;
- наличие постороннего шума.

## Прибор определяет неправильные аккорды

Распознавание аккорда зависит от качества спектрального анализа.

На результат влияют:

- шум;
- обертоны;
- недостаточный уровень сигнала;
- несколько одновременно звучащих инструментов;
- реверберация;
- слишком короткое окно анализа;
- особенности настройки инструмента.

Для получения стабильного результата желательно подавать относительно чистый сигнал.
